## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/vivek061205/FullStack-Vivek.git
   ```

2. Open any task folder.
3. Open its `index.html` file in a browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
